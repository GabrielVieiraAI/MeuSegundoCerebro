# SAP Learning - Practicing Clean Core Extensibility for SAP S/4HANA Cloud
## Quiz Oficial: Understanding the Consumer-Grade User Experience Concept

> [!NOTE] Instruções de Estudo Ativo

### Pergunta 1
**Quais das seguintes alternativas são motivos pelos quais uma experiência do usuário de nível de consumidor (*Consumer-Grade UX*) é importante?**  
*(Selecione todas as opções corretas - Múltipla Escolha - 3 respostas corretas)*

- **A.** Ganhos de produtividade (*Productivity gains*)
- **B.** Economia nos custos de treinamento (*Training cost savings*)
- **C.** Redução de erros cometidos pelos usuários (*Reduction in user errors*)
- **D.** Fortalecimento do relacionamento com clientes e parceiros (*Strengthening of customer and partner relationships*)

> [!success]- Gabarito e Explicação Oficial da SAP
> **Respostas Corretas:** **A, B e C**  
> 
> **Fundamentação Oficial da SAP:**  
> Uma experiência de usuário (*UX*) de nível de consumidor é importante para obter **ganhos de produtividade**, **economia nos custos de capacitação/treinamento** e **redução drástica de erros operacionais cometidos pelos usuários**.  
> O fortalecimento de relacionamentos com clientes e parceiros é um efeito corporativo indireto, mas não é listado pela SAP como um dos impactos operacionais primários da adoção de uma UX moderna.

### Pergunta 2
**Quais dos seguintes itens são blocos de construção (*building blocks*) da abordagem de design do SAP Fiori?**  
*(Selecione todas as opções corretas - Múltipla Escolha - 3 respostas corretas)*

- **A.** SAPUI5
- **B.** Python
- **C.** SAP Fiori elements
- **D.** SAP Business Application Studio

> [!success]- Gabarito e Explicação Oficial da SAP
> **Respostas Corretas:** **A, C e D**  
> 
> **Fundamentação Oficial da SAP:**  
> **SAPUI5**, **SAP Fiori elements** e o **SAP Business Application Studio (BAS)** são os blocos de construção oficiais da abordagem de desenvolvimento e design do SAP Fiori.  
> A linguagem Python não faz parte do conjunto de ferramentas de desenvolvimento de frontend do SAP Fiori.

### Pergunta 3
**Quais dos seguintes produtos fazem parte do conjunto de ferramentas Low-Code / No-Code (LCNC) da SAP?**  
*(Selecione todas as opções corretas - Múltipla Escolha - 3 respostas corretas)*

- **A.** SAP Build Apps
- **B.** SAP Build Process Automation
- **C.** SAP HANA Cloud
- **D.** SAP Build Work Zone

> [!success]- Gabarito e Explicação Oficial da SAP
> **Respostas Corretas:** **A, B e D**  
> 
> **Fundamentação Oficial da SAP:**  
> O portfólio LCNC oficial da família **SAP Build** é composto exatamente por: **SAP Build Apps** (criação no-code de aplicações), **SAP Build Process Automation** (automação de workflows e processos) e **SAP Build Work Zone** (criação de portais e digital workplaces).  
> O *SAP HANA Cloud* é uma solução de banco de dados e persistência como serviço (DBaaS), não uma ferramenta LCNC de construção visual para builders.

### Pergunta 4
**Qual dos seguintes recursos do SAP Build é voltado especificamente para um desenvolvedor cidadão (*Citizen Developer / Builder*)?**  
*(Selecione uma opção - Resposta Única)*

- **A.** Depurador integrado (*Integrated debugger*)
- **B.** Utilização de uma linguagem ou modelo de programação específico (*Utilization of a particular language and/or programming model*)
- **C.** Recursos avançados de teste (*Advanced testing capabilities*)
- **D.** Ferramentas gráficas intuitivas com geração de código (*Intuitive graphical tools utilizing code generation*)

> [!success]- Gabarito e Explicação Oficial da SAP
> **Resposta Correta:** **D**  
> 
> **Fundamentação Oficial da SAP:**  
> No SAP Build, as **ferramentas gráficas intuitivas que utilizam geração automatizada de código** são projetadas especificamente para o desenvolvedor cidadão (*Builder*).  
> Depuradores integrados (*debuggers*), linguagens de programação formais e recursos avançados de testes automatizados são ferramentas voltadas para desenvolvedores profissionais tradicionais (*pro-code*).

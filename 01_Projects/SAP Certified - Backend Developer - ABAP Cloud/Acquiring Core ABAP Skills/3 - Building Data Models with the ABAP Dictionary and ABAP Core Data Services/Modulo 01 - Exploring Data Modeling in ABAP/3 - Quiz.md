# SAP Learning - Building Data Models with the ABAP Dictionary and ABAP Core Data Services
## Quiz Oficial: Exploring Data Modeling in ABAP

> [!NOTE] Instruções de Estudo Ativo

---

### Pergunta 1
**Quais dos seguintes objetos do ABAP Dictionary você pode utilizar como tipos de dados no código ABAP?**  
*(Selecione todas as opções corretas - Múltipla Escolha)*

- **A.** Domínio (*Domain*)
- **B.** Elemento de Dados (*Data Element*)
- **C.** Estrutura (*Structure*)
- **D.** Tabela de Banco de Dados (*Database Table*)

> [!success]- Gabarito e Explicação Oficial da SAP
> **Respostas Corretas:** **B, C e D**  
> 
> **Fundamentação Oficial da SAP:**  
> Você pode utilizar elementos de dados, estruturas e tabelas de banco de dados como tipos de dados no código ABAP.  
> Domínios são utilizados apenas no interior de elementos de dados; você não pode utilizá-los como tipos de dados no código ABAP. No entanto, você pode utilizar definições de tabelas de banco de dados como tipos de dados — embora isso não seja recomendado.

---

### Pergunta 2
**Quais das seguintes alternativas são tarefas do ABAP Core Data Services?**  
*(Selecione todas as opções corretas - Múltipla Escolha)*

- **A.** Definir visões no banco de dados (*Define views on the database*).
- **B.** Definir tabelas no banco de dados (*Define tables on the database*).
- **C.** Fornecer serviços para interfaces de usuário clássicas do ABAP (*Provide services for classical ABAP user interfaces*).
- **D.** Definir Business Objects no ABAP RESTful application programming model (*Define Business Objects in the ABAP RESTful application programming model*).

> [!success]- Gabarito e Explicação Oficial da SAP
> **Respostas Corretas:** **A e D**  
> 
> **Fundamentação Oficial da SAP:**  
> O ABAP Core Data Services é utilizado para definir visões semanticamente enriquecidas e Business Objects no ABAP RESTful Application Programming Model (RAP).  
> A definição de tabelas de banco de dados e o fornecimento de serviços para interfaces de usuário clássicas do ABAP são tarefas do ABAP Dictionary.

## 🛠️ 4. Matriz Rápida de Competências por Módulo

> [!TIP] O Que a SAP Cobra Neste Curso
> - **Módulo 01 (Ambiente & Logística):** Diferença entre ABAP clássico e [[ABAP Cloud]], [[Clean Core]], conexão no Eclipse ADT via Service Key ou Logon no SAP BTP, pacotes de software, tipos de pacotes e a interface executável de console `IF_OO_ADT_CLASSRUN`.
> - **Módulo 02 (Técnicas Básicas):** Tipagem básica (`i`, `string`, `p` com `DECIMALS`, `c`, `n`, `d`, `t`), declarações inline `DATA(...)`, string templates `|...|`, estruturas condicionais (`IF`, `CASE`), laço `DO` e `LOOP AT`, e as teclas do debugger ADT (**F5, F6, F7, F8**).
> - **Módulo 03 (Classes Locais & POO):** Classes locais na aba *Local Types*, seções estritas (`PUBLIC` $\rightarrow$ `PROTECTED` $\rightarrow$ `PRIVATE`), atributos `DATA` vs `CLASS-DATA`, métodos funcionais com `RETURNING VALUE(...)`, encapsulamento com `READ-ONLY`, ciclo de vida do `CONSTRUCTOR` e `CLASS_CONSTRUCTOR`, e a armadilha de referências `ref2 = ref1`.
> - **Módulo 04 (Acesso a Banco de Dados):** Leitura de dados via `SELECT` simples e projeção em tabelas, introdução às [[CDS - Core Data Services|CDS Views]], arquitetura de visualização direta e separação entre modelo de dados e camada lógica.
> - **Módulo 05 (Estruturas de Dados):** Declaração de `TYPES` locais estruturados, comandos `DATA wa TYPE ...`, estruturas aninhadas, acesso a componentes com o operador traço (`wa-campo`) e mapeamento `CORRESPONDING #( )`.
> - **Módulo 06 (Tabelas Internas Complexas):** Criação de tabelas com linhas estruturadas, tipos de tabela, operações de manipulação em lote, expressões de construtor `VALUE #( ... )` e iterações seguras.
> - **Módulo 07 (Atualizações via Business Objects):** Transição de escrita direta em tabelas para o uso de Business Objects governados, introdução à EML (*Entity Manipulation Language*) com comandos `MODIFY ENTITIES`, `COMMIT ENTITIES` e regras de integridade transacional.
> - **Módulo 08 (Modelo RAP - ABAP RESTful Application Programming Model):** Arquitetura geral do [[RAP - ABAP RESTful Application Programming Model|RAP]], CDS Data Definitions, Behavior Definitions (`BDEF`), Services Definitions, Service Bindings (OData V2/V4) e a experiência de ponta com SAP Fiori Elements.

## 🗣️ 2. Técnica Feynman (Slides do Apresentador)

> [!ABSTRACT]- Clique para expandir os Slides de Apresentação (Passo 6)
> ### Slide 1: A Transição do Clássico para o Cloud
> - **O que mudou:** Sem SE38/SE80. Obrigatoriedade do Eclipse ADT.
> - **ABAP Project vs ABAP Cloud Project:** O primeiro conecta a On-Premise/Private Cloud; o segundo conecta a BTP e S/4HANA Public Cloud com regras estritas de Clean Core.
> 
> ### Slide 2: A Hierarquia da Nuvem
> - **Infraestrutura:** Global Account -> Subaccount -> Runtime (Cloud Foundry/Kyma) -> Instância ABAP.
> - **Organização de Código:** Software Component (ex: `ZLOCAL`) -> Pacote customizado (`Z...` ou `Y...`) -> Objetos.
> 
> ### Slide 3: Sua Primeira Aplicação de Console
> - **Sem Dynpro/Telas:** Como rodar código rápido? Implementando a interface `if_oo_adt_classrun`.
> - **Método `main`:** Recebe a referência `out` do tipo `if_oo_adt_classrun_out`.
> - **Saída e Execução:** `out->write( 'Hello World' )` executado com o atalho **F9**.
> 
> ### Slide 4: Ciclo de Vida e Ferramental Moderno
> - **Inativo vs Ativo:** Alterações salvas permanecem inativas até a ativação explícita com **Ctrl + F3**.
> - **Atalhos Essenciais:** **F3** (navegar para definição), **F2** (documentação rápida).
> - **IA Integrada:** Joule (*Explain* e completion) e o novo *ABAP AI SDK*.

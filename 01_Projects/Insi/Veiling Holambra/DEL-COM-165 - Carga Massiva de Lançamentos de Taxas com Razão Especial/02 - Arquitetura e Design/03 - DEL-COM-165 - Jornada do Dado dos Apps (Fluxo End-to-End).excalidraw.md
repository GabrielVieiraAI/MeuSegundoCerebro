1. SAP Fiori Elements (UI Standard com Draft)
• Usuário cadastra regra de taxa (ex: Tipo 'TF')
• Informa Vigência, Chave Lançamento e Razão Esp.
• Zero JavaScript: List Report + Object Page nativo ^t2step01

2. Exposição OData V4 (Service Layer)
• Service Definition: ZUI_FI_TAX_TPMOV
• Service Binding: ZUI_O4_FI_TAX_TPMOV
• Protocolo moderno com suporte nativo a Draft ^t2step02

3. Modelagem de Dados CDS
• Root CDS View: ZI_FI_TAX_TPMOV (Camada Interface)
• Projection View: ZC_FI_TAX_TPMOV (Consumo UI)
• Metadata Extension (MDE) define facetas e campos ^t2step03

4. Comportamento RAP (Managed com Draft)
• BDEF ZI_FI_TAX_TPMOV gerencia ciclo transacional
• Gravação silenciosa de rascunho em ZTFI_TAX_TPMOV_D
• Rascunho isolado: não impacta dados produtivos ^t2step04

5. Behavior Pool: ZCLFI_BP_TAX_TPMOV
• Determinations: Bloqueio='T', Blart='21', Ativo='X'
• Validations: vigência temporal sem sobreposição
• Validação de Razão Especial (UMSKZ) válido no SAP ^t2step05

6. Tabela Ativa: ZTFI_TAX_TPMOV
• Ao clicar 'Salvar', rascunho é promovido a dado mestre
• Guarda as 'Leis de Zoneamento' oficiais ativas
• Fonte de verdade consultada em tempo real pelo App 1 ^t2step06

CONSULTA DE REGRAS
• Razão Esp. (UMSKZ)
• Bloqueio Pagto (T)
• Contrapartida (DS-ATR) ^tbridge1

1. Fiori Elements + Controller Extension (Upload)
• Usuário faz drag-and-drop da planilha .xlsx na UI
• Controller JS lê o arquivo binário e codifica em Base64
• Invoca action OData 'carregarArquivo' enviando payload ^t1step01

2. Abstract Entity: ZI_FI_TAX_ARQUIVO (Doca Efêmera)
• Entidade puramente lógica em memória (sem tabela no DB)
• Recebe e descarrega o binário Base64 no backend RAP ^t1step02

3. Motor XCO Excel: ZCLFI_TAX_EXCEL
• Descompacta o .xlsx em memória RAM via XCO_CP_XLSX
• Pula cabeçalhos decorativos e lê 15 colunas a partir da lin. 6
• Converte planilha em tabela interna ABAP estruturada ^t1step03

4. Behavior Pool: ZCLFI_BP_TAX_CARGA (Orquestrador)
• Agrupa partidas por DOCSEQ (documento contábil preliminar)
• Aplica regras da ZTFI_TAX_TPMOV (UMSKZ, Bloqueio, Blart)
• Gera contrapartida automática para DS-ATR (Conta 2205010002)
• Executa simulação contábil via BAPI_ACC_DOCUMENT_CHECK ^t1step04

5. Staging Persistido em 3 Níveis (Sem Draft)
• Nível 1: Lote (ZTFI_TAX_CARGA) - ID via SNRO ZTAXCARNR
• Nível 2: Documentos (ZTFI_TAX_DOC) - Status simulação
• Nível 3: Itens (ZTFI_TAX_ITEM) - Detalhe das partidas
• Sem reprocessamento na UI: erros corrigidos no Excel ^t1step05

6. Fiori Monitor: List Report & Object Page (Conferência)
• Projeções CDS (ZC_FI_TAX_CARGA/DOC/ITEM) e MDEs
• Usuário audita contadores, totais e status de cada documento
• Usuário aciona o botão de ação: 'Contabilizar Lote' ^t1step06

7. Contabilização Oficial: Wrapper BAPI & Clean Core
• save_modified aciona ZCLFI_TAX_BAPI_WRAP (BAPI_POST)
• Clean Core: BAPI executa sem COMMIT; RAP gerencia o COMMIT
• Grava BELNR e GJAHR em ZTFI_TAX_DOC e finaliza Lote ^t1step07

# O Guia Definitivo do Método PARA (De Forma Simples)

Se você já tentou organizar suas anotações e acabou com uma bagunça de pastas que não fazem sentido, você não está sozinho. O método **PARA** (criado por Tiago Forte) serve para organizar qualquer tipo de informação digital com foco em **ação** (o que você está fazendo agora) em vez de focar no assunto.

A sigla PARA significa:
- **P**rojects (Projetos)
- **A**reas (Áreas)
- **R**esources (Recursos)
- **A**rchive (Arquivo)

---

## 1. Entendendo o PARA de uma vez por todas

Esqueça a ideia de organizar as coisas como se fosse uma biblioteca (por assunto). Pense na sua organização como uma **cozinha**.

### 🍲 Projects (Projetos) = O que está no fogão agora
**Definição:** Coisas que você está ativamente trabalhando, que têm um **prazo final** (ou uma data de conclusão) e um **objetivo claro**.
- *Exemplos:* "Organizar a festa de aniversário da Maria", "Publicar o artigo sobre IA", "Comprar um notebook novo".
- *Regra de ouro:* Se não acaba nunca, não é um projeto. Se você pode marcar um "Check/Feito", é um projeto.

### 🏠 Areas (Áreas) = A despensa e a manutenção da casa
**Definição:** Responsabilidades contínuas que você precisa manter ao longo do tempo. Não têm um prazo final, são áreas da sua vida ou do seu trabalho que exigem atenção regular.
- *Exemplos:* "Saúde", "Finanças Pessoais", "Carreira", "Casa", "Estudos".
- *Regra de ouro:* São as coisas que você tem que cuidar para a vida não desandar. Se um Projeto ("Fazer check-up médico") acaba, a Área ("Saúde") continua.

### 📚 Resources (Recursos) = O seu livro de receitas
**Definição:** Interesses, referências ou assuntos sobre os quais você quer aprender ou guardar informações para o futuro, mas que **não** são uma responsabilidade e não estão ativos em um projeto agora.
- *Exemplos:* "Dicas de produtividade", "Receitas saudáveis", "Anotações sobre Inteligência Artificial", "Ideias de design".
- *Regra de ouro:* É a sua biblioteca pessoal de interesses. Se você parar de ler sobre isso hoje, sua vida não muda (diferente de uma Área).

### 📦 Archive (Arquivo) = O porão / Sótão
**Definição:** Tudo das três pastas acima que não está mais ativo. 
- *Exemplos:* Projetos concluídos (ou abandonados), Áreas que não fazem mais parte da sua vida, Recursos que você não tem mais interesse.
- *Regra de ouro:* Nunca apague nada, apenas jogue no Arquivo. Isso tira a "tralha" da sua frente, mas permite buscar caso precise um dia.

---

## 2. Como decidir onde guardar uma nota? (O Teste de 4 Perguntas)

Sempre que criar uma nota ou arquivo novo, pergunte a si mesmo onde ele deve ficar, **nesta exata ordem** (de cima para baixo):

1. **Isso é útil para algum PROJETO que estou fazendo agora?**
   - *Sim:* Guarde na pasta do Projeto.
   - *Não:* Passe para a pergunta 2.
2. **Isso é útil para alguma ÁREA de responsabilidade da minha vida?**
   - *Sim:* Guarde na pasta da Área.
   - *Não:* Passe para a pergunta 3.
3. **Isso é sobre um assunto que me interessa (RECURSO)?**
   - *Sim:* Guarde na pasta de Recursos.
   - *Não:* Passe para a pergunta 4.
4. **Isso já foi útil, mas não é mais?**
   - *Sim:* Mande para o ARQUIVO.

## 3. Passo a Passo para uma IA Criar Suas Pastas Sozinha

Se você quiser pedir para uma Inteligência Artificial (como eu, ou ChatGPT, Claude, etc.) organizar seu sistema de pastas no computador ou em um aplicativo de notas do zero, você pode usar um **Prompt (Comando)** específico.

Como vi que você já tem a estrutura inicial criada aqui (`00_Inbox`, `01_Projects`, etc.), vou deixar abaixo o comando exato que você pode enviar para uma IA no futuro caso queira que ela recrie essa estrutura ou a expanda para você em outro lugar.

### 🤖 Prompt / Instrução para a IA:

Copie o texto abaixo e cole no chat com a IA:

```text
Atue como um especialista em produtividade e organização digital. Eu quero implementar o Método PARA (Projects, Areas, Resources, Archive) no meu sistema de arquivos/notas.

Por favor, crie um script ou execute a criação da seguinte estrutura de pastas raiz no meu diretório:

1. 01_Projects
2. 02_Areas
3. 03_Resources
4. 04_Archive
5. 00_Inbox (Pasta extra para capturar ideias rápidas antes de organizá-las)

Além disso:
- Dentro de '02_Areas', crie subpastas genéricas para: 'Saúde', 'Finanças', 'Carreira' e 'Casa'.
- Dentro de '03_Resources', crie subpastas genéricas para: 'Ideias', 'Estudos' e 'Referências'.
- Crie um arquivo .txt (ou .md) vazio dentro de cada pasta principal chamado "00_LEIA-ME.md" com uma breve frase explicando o que deve entrar ali segundo o método PARA.

Se você for um Agente de IA com permissões no meu sistema (como o Antigravity), por favor execute a criação das pastas e arquivos agora mesmo usando suas ferramentas. Se você for apenas um chat de texto, me dê os comandos de terminal copiáveis (para Windows/PowerShell) para eu rodar.
```

*Dica:* Quando usar IAs agentivas (que podem modificar arquivos, como eu), dar permissões explícitas no prompt dizendo "execute a criação das pastas" é a forma mais rápida de automatizar o processo!
